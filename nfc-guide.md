# VELORA TAP — NFC Programming Guide

## 1. Purpose

VELORA TAP NFC cards and stickers allow customers to open a business profile by tapping their NFC-enabled smartphone.

The NFC tag and QR code should open the same business profile URL.

## 2. Business Profile URL

Every business must have its own unique URL.

Example:

`https://your-domain.com/abc-restaurant`

Use the actual deployed domain when available.

## 3. Required Equipment

- NFC-enabled smartphone
- Compatible NFC card or sticker
- NFC Tools mobile application
- Internet connection
- VELORA TAP business profile URL

## 4. Programming Instructions

1. Open the NFC Tools application.
2. Select Write.
3. Select Add a record.
4. Choose URL / URI.
5. Enter the business's VELORA TAP profile URL.
6. Select Write.
7. Hold the NFC card or sticker against the phone's NFC area.
8. Wait for the successful write confirmation.

## 5. Testing

After programming:

1. Enable NFC on a compatible smartphone.
2. Tap the card or sticker.
3. Confirm that the correct business profile opens.
4. Test Google Reviews.
5. Test the website link.
6. Test WhatsApp.
7. Test Instagram.
8. Scan the QR code and confirm that it opens the same profile.

## 6. Important Notes

- Each business must have its own unique profile URL.
- Do not program all customer cards with the same business URL.
- Test every NFC tag before delivery.
- Keep a record of each programmed business URL.
- Avoid placing NFC stickers directly against metal surfaces.
- QR and NFC should point to the same destination.
